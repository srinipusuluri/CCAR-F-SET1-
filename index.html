Decision rule — enforcement: when compliance must be guaranteed (identity verification before a refund, a spend threshold, a required review step), use programmatic enforcement (a hook or prerequisite gate). Prompt instructions, however clear, remain probabilistic and are not a substitute.

Structured output & reliability

tool_use + JSON Schema — the most reliable way to eliminate output syntax errors (not semantic errors).
Nullable/optional fields — prevent the model from fabricating a value when information is genuinely absent from the source.
Message Batches API — ~50% cost savings, up to a 24-hour window, no SLA, no multi-turn tool calling; fits latency-tolerant, non-blocking workloads only.
Lost-in-the-middle effect — long inputs are processed less reliably in the middle than at the start/end.
Case facts block — a persistent, structured summary of key facts kept outside progressively-summarized history.
Escalation triggers — an explicit human request, a policy gap, or genuine inability to progress; never sentiment or self-reported confidence alone.

Glossary

stop_reason — the field distinguishing "tool_use" (continue the loop) from "end_turn" (stop).
AgentDefinition — the configuration for a subagent type: description, system prompt, and tool restrictions.
allowedTools — the list of tools an agent may use; must include "Task" for a coordinator to spawn subagents.
isError — the MCP flag pattern for reporting a tool call failure.
errorCategory / isRetryable — structured error metadata distinguishing transient, validation, business, and permission errors.
@import — CLAUDE.md syntax for referencing external files to keep configuration modular.
.claude/commands/ — project-scoped custom slash commands, shared via version control.
context: fork — SKILL.md frontmatter that runs a skill in an isolated sub-agent context.
/memory, /compact — inspect which configuration files are loaded; reduce context usage in long sessions.
--resume <session-name> — continue a specific named prior session.
custom_id — the field correlating Message Batches API requests with their responses.
tool_choice — "auto", "any", or a forced named tool.
Explore subagent — isolates verbose codebase-discovery output from the main session.
Scratchpad file — a file an agent uses to persist key findings across context boundaries.
Stratified sampling — sampling by segment (e.g., document type) to catch accuracy problems an aggregate metric would mask.
Claim-source mapping — a structured link between a synthesized finding and the source it came from, preserved through summarization.
Five reflexes that pass this exam:
  1. When a rule must be guaranteed, enforce it programmatically (a hook or gate) — never trust a prompt instruction alone.
  2. Subagents don't inherit context automatically — pass what they need explicitly, and diagnose coverage gaps as coordinator decomposition problems first.
  3. Match the API/architecture to the workload's actual latency and volume constraints (batches vs. real-time; plan mode vs. direct execution).
  4. Prefer structured, schema-based output for anything downstream systems consume — and use nullable fields instead of letting the model fabricate.
  5. Preserve provenance and structured error context through every hand-off, so a coordinator or human reviewer can actually recover or reconcile.
